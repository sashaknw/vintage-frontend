
# Vintage Vault 👗 (scroll down for version in SP)

## Description
Vintage Vault is a digital marketplace for vintage clothing and accessories. The platform offers an intuitive and visually appealing shopping experience for vintage fashion enthusiasts, combined with community forum for sharing fashion tips and discoveries.

## 🛠️ Technologies Used
* **Frontend:** React + Vite
* **Styling:** Tailwind CSS with custom theme. DaisyUI for small elements.
* **Backend:** Express + MongoDB + Mongoose
* **Authentication:** JWT + bcrypt
* **Image Storage:** Cloudinary
* **Deployment:**
  * Frontend: Netlify
  * Backend: Render
* **State Management:** React Context API + Hooks
* **Routing:** React Router v6

## ✨ Key Features

### 👚 Product Management
* Detailed product visualization
* Multiple image gallery with hover effects
* Condition indicators (Mint, Good, Rugged)
* Era categorization (50s, 60s, 70s, 80s, 90s, Y2K)
* Complete product management for admins (CRUD)

### 🛒 Shopping Cart
* Add/remove products
* Quick access from navigation
* Data persistence

### 🔍 Search and Filters
* Filter by clothing category, era, size, condition, price-range
* Multi-parameter search

### 💬 Community Forum
* Category-based discussions
* User profiles: private, public
* Topic creation and replies
* Pinned and admin topics
* Topic following
* Favorites sharing

### 👤 User Management
* Registration and authentication
* Profile customization
* Favorites collection
* Order history

### 💻 User Interface
* Responsive design with special features for phones
* Interactive product gallery
* Custom yellow and black theme
